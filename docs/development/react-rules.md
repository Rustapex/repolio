# React 구현 규칙

## 컴포넌트와 상태

- 함수형 컴포넌트와 명시적인 props 타입을 사용한다.
- 화면 전체에 영향을 주는 상태는 `App.tsx` 또는 가장 가까운 공통 부모에 둔다. 한 컴포넌트에서만 쓰는 상태는 해당 컴포넌트에 둔다.
- 필터 결과, 언어 목록, 그룹 목록처럼 기존 데이터와 상태로 계산할 수 있는 값은 상태로 복제하지 않고 `useMemo`와 `src/lib/`의 순수 함수로 계산한다.
- 브라우저 API, 저장소, 미디어 쿼리처럼 수명주기 처리가 필요한 동작은 `useX` 훅으로 분리한다.

## 데이터와 표시의 분리

- 카탈로그 정규화, 그룹 결합, 필터, 정렬은 `src/lib/`에서 수행한다.
- 컴포넌트는 데이터를 받으면 로딩·빈 상태·오류 또는 경고 상태를 사용자가 이해할 수 있게 표시한다.
- 외부 링크는 새 탭을 열 때 `rel="noreferrer"`를 사용하고, 아이콘만 있는 조작에는 접근 가능한 이름을 제공한다.
- README 렌더링 변경은 안전한 Markdown 처리와 현재의 제한된 미리보기 흐름을 유지한다.

## 타입과 스타일

- 데이터 모델과 필터의 공용 타입은 `src/types/repository.ts`에서 가져온다. 같은 모델을 컴포넌트마다 다시 선언하지 않는다.
- 타입 전용 가져오기는 `import type`을 사용한다.
- 클래스 이름과 CSS 변경은 `docs/design/design-rules.md` 및 `src/styles/`의 현재 분리를 따른다.

## 검증

- 필터, 그룹, README 처리, 동기화 변환의 동작을 바꾸면 `tests/`의 집중 테스트를 추가하거나 갱신한다.
- 구현을 마치면 최소 `npm test`와 `npm run build`를 실행한다.
